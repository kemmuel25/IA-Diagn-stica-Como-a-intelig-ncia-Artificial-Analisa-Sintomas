# IA-Diagn-stica-Como-a-intelig-ncia-Artificial-Analisa-Sintomas
1. Coleta informações → sintomas + tempo + intensidade   2. Organiza os dados   3. Compara com um banco de padrões   4. Procura semelhanças   5. Gera hipóteses possíveis   6. Classifica urgência (leve, moderada, alta)   7. Dá recomendações gerais (ex.: beber água, procurar médico, sinais de alerta)
