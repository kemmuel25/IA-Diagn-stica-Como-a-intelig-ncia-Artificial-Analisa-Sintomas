# IA Diagnóstica — Sistema Educacional (Versão X)

Este projeto demonstra como uma IA **educativa** organiza sintomas, compara com padrões simples e gera hipóteses e recomendações gerais — **não é diagnóstico médico**.

⚠️ **Aviso obrigatório**
> Este projeto é educativo. Não fornece diagnósticos reais. Procure um profissional de saúde para avaliação médica.

## Objetivo
Mostrar de forma clara e segura como um sistema baseado em regras analisa sintomas e sugere hipóteses para fins educacionais (por exemplo: feira de ciências, apresentação).
